# Prompt Improvement Task

## Objective
Iteratively improve the following prompt to make it more effective for a model to classify product ideas into implementation categories (web app, mobile app, Chrome extension, etc.).

### Original Prompt
"I have created many product briefs. I want you to go through each and every product brief and find out how we can classify this idea so that it will be easier for me to implement them. By classify, I mean what kind of application we need to do, like a web app, mobile app, Chrome extension, or anything else. For now, do just that."

## Deliverables
- An improved, structured prompt that clearly defines the classification task, provides examples, and sets expectations for the output format.

## Constraints
- The improved prompt must be compatible with standard LLMs.
- It should encourage detailed reasoning for each classification.
